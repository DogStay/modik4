CACHE MOD — ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
====================================

Порядок проверки повторяет порядок разработки: пока «обыскать → анимация →
сундук» не работает, остальное проверять бессмысленно.

1. СТАРТ СЕРВЕРА
   В RPT должно быть:
     [CACHE_MOD] INFO:  Конфигурация загружена: точек N, зон M, тиров K.
     [CACHE_MOD] INFO:  Активных тайников в этом запуске: A из N.
   В $profile:CacheMod появились settings.json, caches.json, loot_zones.json,
   loot_tiers.json, admins.json.

2. РАЗМЕЩЕНИЕ
   Взять CacheCreatorBook_Basic, включить размещение, F.
   RPT:
     [CacheMod/Placement] INFO:  Тайник cache_001 создан игроком 7656...
     [CacheMod/Interaction] INFO:  Proxy создан для cache_001 ...
   Книга осталась в руках. На земле книги нет. В caches.json появилась запись.

3. НЕВИДИМОСТЬ
   Обычный игрок (без @CacheMod_Admin) в точке не видит ничего: ни ящика, ни
   сферы. При наведении на место тайника появляется действие «Обыскать».

4. ОБЫСК
   Зажать действие. Персонаж встаёт в анимацию работы у земли, идёт прогресс.
   Отпустить раньше времени — ничего не создаётся, действие доступно снова.
   Отойти во время обыска — действие отменяется.
   Резко развернуться — действие отменяется.

5. РЕЗУЛЬТАТ
   Довести обыск до конца. RPT:
     [CacheMod/Search] INFO:  Обыск cache_001 завершён игроком ...
     [CacheMod/Zone]   INFO:  Точка ... вне зон → тир по умолчанию 'civilian'.
     [CacheMod/Chest]  INFO:  Сундук для cache_001 создан в ...
     [CacheMod/Loot]   INFO:  Сгенерировано предметов: X ...
   В точке стоит видимый сундук, внутри лут. Действие «Обыскать» больше не
   появляется.

6. ЛУТ-ЗОНА
   В loot_zones.json задать зону вокруг точки (tier "military", radius 300),
   нажать ПЕРЕЧИТАТЬ в Cache Manager, дождаться респавна и обыскать снова.
   RPT должен показать:
     [CacheMod/Zone] INFO:  Точка ... в зоне 'ваш_id' → тир 'military'.
   Сам тайник в caches.json при этом не менялся — тир в нём не хранится.

7. СУНДУК
   При "despawn_when_empty": true пустой сундук исчезает на ближайшем тике
   (до 10 секунд). Иначе — по истечении lifetime_seconds.

8. РЕСПАВН
   Дождаться respawn_seconds. RPT:
     [CacheMod/Respawn] INFO:  Тайник cache_001 снова доступен.
   Действие «Обыскать» снова появляется в той же точке.

9. РЕСТАРТ
   Перезапустить сервер. В RPT — строка «Ролл cache_XXX: шанс ..., выпало ...»
   для КАЖДОЙ точки, и итоговая строка с количеством активных. Количество от
   запуска к запуску меняется — это правильно.
   Тайник, обысканный за минуту до рестарта, после рестарта всё ещё на
   кулдауне: время считается в UTC и лежит в caches.json.

10. АДМИНСКИЕ СФЕРЫ
    Cache Manager -> СФЕРЫ. Видны сферы радиусом ровно cache.radius:
      зелёная  — ACTIVE
      серая    — INACTIVE (spawn chance не прокнул)
      красная  — COOLDOWN
      жёлтая   — ACTIVE, требуется инструмент
    Обычный игрок сфер не видит и списка точек не получает.

11. ПРАВА
    Снять право MenuCacheManager и убрать Steam64 из admins.json.
    Попытка разместить книгой:
      [CacheMod/Placement] WARN:  Размещение отклонено: у 7656... нет прав.
    Игроку приходит «У вас нет прав на размещение тайников.»

12. TOOL_REQUIRED
    В Cache Manager выставить точке тип TOOL_REQUIRED и инструмент Shovel.
    Без лопаты действие не появляется. С лопатой в руках — появляется.
    При "tool_in_hands_only": false лопата в рюкзаке тоже подходит.
